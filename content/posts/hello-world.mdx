Welcome to my personal site! This is the first post.

## Why this site

I wanted one place for:

- A portfolio of projects
- Technical notes
- The occasional casual post

## The stack

React + Vite + TypeScript + Tailwind CSS, with blog content in MDX:

```tsx
export default function Hello() {
  return <h1>Hello World</h1>
}
```

Writing a new post is just dropping a `.mdx` file into `content/posts/`.
